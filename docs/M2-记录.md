# M2 教务导入 · 实现记录

日期：2026-10-29
状态：已完成（2026-10-30，用户在新版正方 jwglxt 教务页面验证通过）

## 功能

首页右下角 FAB → **教务导入**：

1. 点 FAB 里的「教务导入」，**先弹对话框输入教务网址**（http / https 都支持，记住上次地址）。
2. 点「打开」进入内嵌 WebView，手动登录（验证码、SSO、校园网 VPN 都交给用户操作，App 不保存账号密码）。
3. 进入「个人课表」页面后点右上角 **抓取本页**。
4. 本地解析并显示预览：识别出的模板、课程数、每门课的星期/节次/周次/教室。
5. 点 **导入 N 门课程**，新建一张课表并自动切换过去。
6. 导入完成后弹「课表已导入」对话框，可直接给新课表重命名；保存或点“稍后”都会回到首页。

HTML 抓取会带上页面里 iframe 的内容（部分教务系统把课表放在 iframe 里）。
App 只做本地解析，不上传页面，也不调用任何作者服务器。

## 支持的模板

| 模板 | 识别特征 | 解析方式 |
|---|---|---|
| 正方教务（新版 jwglxt） | `#table1` + `.festival` / `.title` | 行内 `.festival` 为节次，单元格 id 第一位为星期，`.title` 为课程名，`p[title=教师/上课地点/节/周]` 取字段 |
| 正方教务（旧版） | `#Table1` | 按“第x节”定位行，按空白切分课程文本，`{第a-b周}` 取周次，`周一第a-b节` 取星期与节次 |
| 强智 | `#kbtable` / `.kbcontent` | `kbcontent` 按 `-----` 拆分课程，`title=老师/教室/周次(节次)` 取字段，按行号推算节次 |

解析结果会按课程名合并，上课安排去重；颜色按课程名散列分配。

新版正方增加了容错（2026-10-30）：

- `festival` 缺失时不再整行跳过，节次改为从时间文本里取；
- 单元格 id 不是“1-1”形式时，按该行第几个课程列推算星期；
- 课程容器本身带 `title` class（而不是子元素）也能识别；
- 星期 id 里含任意数字都能提取，不再要求首字符是数字。
- 兼容“字段值放在 `span[title=…]` 后面的同级 `<font>` 里”的结构（某校 jwglxt：`title="教师 "` 带尾随空格；节/周值是 `(1-2节)1-12周`，周次在括号外）。

## 代码位置

- `data/importer/EduScheduleParser.kt`：三套解析器与模板识别（纯 Kotlin + Jsoup）。
- `ui/screens/EduImportActivity.kt`：WebView + 抓取 + 预览 + 导入界面。
- `data/ScheduleRepository.kt`：`importParsedTimetable()` 事务写入课表/课程/安排。
- `ScheduleFab.kt` / `FallAsleepApp.kt`：首页 FAB 的“教务导入”入口，通过 Activity Result 拿到新课表 id 并自动选中。

## 日志与反馈

- 每次教务导入都会写入应用私有日志（`files/edu-import.log`）：
  - 成功：URL、识别到的模板、课程数、HTML 长度；
  - 失败：额外记录错误信息和**整页 HTML**（最多约 150 万字符），用于复现解析问题。
- 导出：设置 → 数据 → **导出日志**，生成 txt，内容包含 App 版本、Android 版本、设备型号和日志本身。
- 日志只存在本机，不会自动上传；失败日志含页面 HTML，**可能包含姓名、学号等个人信息**，发送前请自行检查。
- 反馈流程：复现一次导入失败 → 设置 → 数据 → 导出日志 → 把 txt 发回。

## 需要用户验证的清单

1. **入口**：首页右下角 FAB → 教务导入，先弹出输入教务网址的对话框；填地址点“打开”后进入网页界面；设置页不再有这个入口。
2. **登录**：输入自己学校的教务网址，能正常加载、登录、进入个人课表页。
3. **抓取**：点“抓取本页”，应出现“解析预览”，并显示模板名称与课程数。
4. **字段正确性**：抽查 3–5 门课：
   - 课程名、教师、教室；
   - 星期与节次（例如周二第 3-4 节）；
   - 起止周；单双周课程是否只在对应周出现。
5. **导入结果**：导入后自动切到新表，并弹出重命名对话框；改名保存后，顶栏和新课表名应同步更新；点“稍后”保留默认名。网格位置与教务页面一致；切到单/双周能正确显示或隐藏。
6. **异常**：在教务首页或空白页抓取，应提示无法识别，而不是新建空课表。
7. **日志**：如果新版正方仍然解析失败，去 设置 → 数据 → 导出日志，导出 `FallAsleep-log.txt`；文件里应包含“教务导入失败”、template、错误信息和 HTML。把日志发回即可定位。
8. **回归**：WebView 返回键先回网页历史；预览页返回键回到网页；原有 JSON/旧版导入、FAB、今日课程样式不受影响。

## 验收结果

- 最新测试包在用户学校的新版正方（jwglxt）页面导入成功，用户确认课程与字段正确。
- 老正方 / 强智目前仅通过合成 HTML 样例测试，尚未用真实学校页面验证；等有对应学校的样本再补，不阻塞 M2 收尾。

## 已知限制

- 只支持上述三套模板；其他教务系统（如 URPLUS、青果、教学一体化平台）需要新增解析器。
- 页面结构改版会导致解析失败；失败时请把该页面的 HTML 保存下来发给开发，补成测试样例最快。
- 旧版正方按空格切分文本，对空格/全角空格异常敏感的页面可能解析不全。
- 强智的节次是按行号推算的（沿用旧版 WakeUp 的规则），不同学校的表格行数可能需要微调。
- WebView 需要允许明文 HTTP（已设置 `usesCleartextTraffic=true`），因为不少学校教务仍是 http。
- 导入的是“当前学期”下的一张新表，不会修改学期设置。
