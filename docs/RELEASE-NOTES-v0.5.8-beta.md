## 动效

- **平板周切换**：课表网格与右侧「今日课程」分别滑动、淡入淡出；
  网格横移 1/4 宽度，今日课程横移 1/10 并延迟 30ms，形成分层感。
- **一级页面切换**：课表 / 今日 / 设置之间 180ms 交叉淡入淡出。
- **预测式返回**：
  - 课表始终垫在最下层；
  - 从今日 / 设置侧滑返回时，上层按手势进度右移、淡化，露出真实课表；
  - 取消手势自动回弹，松手后上层在滑开位置淡出，不再闪回；
  - 全屏课表侧滑返回退出全屏。
- **全屏放大**：进入全屏时课表从 94% 放大到 100%，280ms。
- **FAB**：展开时加号旋转 45° 变成叉，收起时转回。
- 切周时增加轻触感反馈。

## 外观

- 设置 → 外观新增「隐藏状态栏」开关：只隐藏顶部状态栏，保留底部手势条。
- 修复退出全屏时状态栏闪一下的问题。
