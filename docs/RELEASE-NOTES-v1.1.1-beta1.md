# FallAsleep 课程表 v1.1.1-beta1

1.1.0 之后的修复版测试。主要处理导入节数一致性、联系页头像手势、深色模式覆盖范围与更新检查时机。

- 版本：`1.1.1-beta1`（versionCode 25）
- 包名：`io.github.tukinokilyowsoo.fallasleeptimetable`
- APK：`FallAsleepTimetable_arm64_v1.1.1-beta1.apk`（arm64-v8a，10,942,315 字节）
- SHA-256：`bc43fd7f4845bdb690985ae641e6aeb9d23a126b9d0fb5ed93f5e9b2ccf570eb`
- 最低系统：Android 8.0（API 26）

## 修复

- 导入时每天节数严格等于实际写入的时间槽数量，不再出现第 5–12 节没有时间的空行。
- 导入课程用到更多节次时，自动补齐缺少的默认时间，课程不会因此消失。
- 覆盖当前课表前增加二次确认；仍保留原有上课时间设置。
- 减少每天节数时，提示有多少课程超出新节数、可能不再显示。
- 文件导入的节次、周次、单双周增加上限校验，避免损坏文件写入异常范围。
- 联系页头像长按改用独立手势消费，弹窗滚动不再抢走长按，减少最小尺寸时的波动。
- 教务导入页、小组件配置页跟随应用深色模式与主题色。
- 自动检查更新改为应用回到前台时节流执行；只在检查成功后记录时间，离线失败不再压住 6 小时。
- 小组件配置页校验 appWidgetId 是否存在。
- 更新单元测试：正式版高于同号 Beta，并补充 Beta 序号比较与导入边界测试。

## 升级说明

- 与 1.1.0 使用相同的 release 签名，可直接覆盖安装并保留数据。
- 从 debug 版升级仍需卸载重装（签名不同），建议先导出 JSON。

## 已知问题

- 文件导入仍默认新建课表；「覆盖当前课表」目前用于教务导入。
- 教务页面改版可能导致解析失效，可通过「导出日志」反馈页面 HTML 片段。
- 「跟随系统」模式下，系统切换深色后小组件会在下次刷新时跟上。
