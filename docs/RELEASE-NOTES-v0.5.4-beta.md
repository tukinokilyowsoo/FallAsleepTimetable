## Niagara 透明今日课程组件（方案 A）

### 信息精简

- 每行只显示三项：**开始时间 / 课程名 / 教室**。
- 去掉“第 n 节”和结束时间，横向字符量约减少 40%。
- 教室为空时只显示时间和课程名。

### 字号更保守

- 按实际字体测量三列的最长文本，再乘 **0.82 安全系数**。
- 自动字号上限从 72sp 降到 **30sp**。
- 手动字号作为“上限”，只能把自动结果调小，不能撑破可用宽度。
- 右侧安全区从 40dp 增加到 **56dp**，避开 Niagara 的字母索引条。

### 高度与行数

- 行数只按当天剩余课程分配，有几门课就占几行，不再预留空槽。
- “显示行数”改为“最大行数”（1–12，默认 12），只用于限制极端情况。
- 组件外层高度仍由 Niagara 的“移动并调整大小”决定；App 无法主动收缩外层高度。
- 背景透明，外层多余高度直接透出壁纸，不会出现空白色块。

## 已知限制

- Niagara 的组件高度由启动器持有，第三方 App 无法按内容自动收缩；只能通过 `minHeight/minResizeHeight` 允许用户拖到一行。
- 关闭「填充屏幕」可避免字母索引条覆盖；保留填充屏幕时依赖 56dp 安全区。
- 自动黑白取色基于整张壁纸亮度，反差极大时可手动指定黑/白。
