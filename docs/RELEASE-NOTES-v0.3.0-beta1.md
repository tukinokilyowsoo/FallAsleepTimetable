# FallAsleep 课程表 v0.3.0-beta1

首个测试版 · 2026-10-30

- 包名：`io.github.fallasleeptimetable`
- 版本：`0.3.0-beta1`（versionCode 3）
- 安装包：`app-release.apk`，约 8.4 MB
- 系统要求：Android 8.0（API 26）及以上

## ⚠️ 安装前必读

- 这是**新的正式签名**，与之前开发用的 debug 包签名不同。如果手机里装过 debug 版，**必须先卸载**（会清空本地数据），否则无法覆盖安装。
- 卸载前建议在旧版里：设置 → 数据 → **导出当前课表**，保存 JSON 备份；装好新版后再导入。
- 首次启动是空课表，可以手动添加课程，或从教务系统导入。

## 本版包含

### 课表
- 多课表切换、周次浏览、当前周定位
- 单双周、起止周、重叠课程分栏
- 今日列高亮、非本周课程淡化
- 全屏查看（隐藏系统栏/导航/标题栏）
- 平板双栏、手机单栏自适应

### 课程与学期
- 添加/编辑/删除课程：名称、教师、教室、星期、节次、周数、单双周、颜色
- 空白格快速添加；课程详情
- 学期：开学日期、总周数、周六/周日显示
- 上课时间：上午/下午节数、单节时长、课间、逐节起止（Material 3 时间盘），上午/下午独立计算

### 导入导出
- 教务系统导入：内嵌 WebView 手动登录 → 抓取个人课表页 → 预览 → 导入 → 重命名
  - 支持新版正方（jwglxt）、老正方、强智三套模板
- JSON 备份导出/导入
- 旧版 WakeUp `.wakeup_schedule` 导入
- 导入失败可在 设置 → 数据 → 导出日志，附页面 HTML 便于排查（注意可能含个人信息）

### 外观与体验
- Material 3、动态取色、自定义主题色
- 浅色/深色、手机与平板自适应
- 今日页：已结束课程灰点 + 删除线

## 已知限制

- 教务解析：新版正方已在真实学校页面验证；老正方/强智目前只有合成样例，欢迎提供页面 HTML 帮助完善。
- 自定义主题色使用 HSV 近似生成 M3 风格配色，不是完整 HCT 色调板。
- 时间设置只有“上午/下午”两段，晚课会归入下午段连续排。
- 暂无：上课提醒、桌面小组件、ICS/CSV 导入导出（M3 后续）。
- 部分学校需要校园网或 VPN 才能访问教务。

## 隐私

- 离线可用，无账号、无自建服务器。
- 导入日志只保存在本机，导出时请自行检查是否包含姓名/学号等敏感信息。
