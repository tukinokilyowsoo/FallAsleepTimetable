## 本次更新

### 上课时间按课表独立

- 每张课表拥有自己的每天节数与每节课起止时间，不再共用一个学期时间表。
- 新建课表默认复制当前课表的配置。
- 设置 → 学期 →「修改上课时间」会先选择目标课表；时间设置弹窗内可打开「将当前时间作用全局」，一次同步到所有课表。
- 学期设置中不再重复提供「每天节数」。
- 首次启动新版会自动迁移旧数据：原有学期时间会复制给每一张已有课表，课表与课程不受影响。

### 导入

- 教务导入预览页新增「覆盖当前课表」：清空目标课表的课程后写入新课程，保留课表名称与上课时间设置，不再弹出重命名。
- 关闭该选项时仍新建课表，并默认沿用当前课表的上班时间。
- JSON 备份选择「一并恢复」时，开学日期与周数写入学期，节次时间写入新导入的课表，不再影响其他课表。
- 教务系统网址会记住上次输入，并可在设置 →「教务导入」中修改或清空。

### 深色模式

- 设置 → 外观新增「深色模式」：跟随系统 / 浅色 / 深色。
- 桌面小组件跟随同一设置，切换后自动刷新；旧版的小组件样式设置会自动迁移。
- 动态取色与自定义主题色在两种模式下均生效。

### 更新提醒与 Beta 计划

- 启动时检查更新，发现新版本后主页底部弹出 Snackbar，右侧提供「更新」入口。
- 自动检查最多 6 小时一次；手动「检查更新」不受限制。
- 版本行左侧可「拒收 / 接收更新提醒」。
- 「检查更新」弹窗内新增「加入 Beta 计划」开关：加入后自动提醒 Beta 版本；手动检查始终包含 Beta。
- 修复 Beta 版本号比较，例如 beta2 现在正确识别为比 beta1 新。

### 联系开发者

- 新头像（圆形、白色细描边）。
- 按住头像会缓慢缩小，松开回弹；长按震动强度指数上升、封顶约 50%，松手线性衰减并弹出彩蛋提示。
- 卡片会随设备姿态轻微 3D 倾斜。
- 哔哩哔哩、小红书、X 按钮点击时弹出关注提示；「转到 GitHub」打开作者主页。

### 图标与欢迎页

- 应用图标改为 Material 3 自适应图标，并提供 Android 13+ 单色主题图标。
- 欢迎页删除全局「下一步」，第 5 页以胶囊按钮「开始使用」直接进入教务导入。
- 今日 ↔ 设置切换减少一层全屏绘制，动画更稳定。

## 升级说明

- 与 v1.0.0 使用相同的 release 签名，可直接覆盖安装并保留数据。
- 从 debug 版升级仍需卸载重装（签名不同），建议先导出 JSON。
- 本次包含数据库升级（v1 → v2），首次启动会自动迁移；降级到旧版本不受支持。

## 已知问题

- 「覆盖当前课表」目前用于教务导入；文件导入仍默认新建课表。
- 教务页面改版可能导致解析失效，可通过「导出日志」反馈页面 HTML 片段。
- 解析模板覆盖正方（新 / 旧）与强智，其他教务系统暂不支持。
- 小组件的下课精准刷新依赖「闹钟和提醒」权限；未授权时最长约 30 分钟刷新一次。
- 「跟随系统」模式下，系统切换深色后小组件会在下次刷新时跟上。
