# M1 数据、课表与编辑 · 完成记录

日期：2026-10-29

## 本次完成

### 数据层（Room 2.8.5 + KSP）

| 表 | 说明 |
|---|---|
| `term` | 学期：名称、开学日期、总周数、每天节数、是否显示周六/周日 |
| `timetable` | 课表：属于某个学期，可有多个（主课表 / 实验 / 考研） |
| `course` | 课程基本信息：名称、教师、颜色序号 |
| `course_session` | 上课安排：星期、起始节、连续节数、起止周、单双周、教室；一门课可多条 |
| `time_slot` | 节次时间（按学期，默认 12 节的上下课时间） |

- 外键级联：删学期 → 删课表 → 删课程 → 删安排。
- `ScheduleRepository` 负责事务写入（保存课程 = 更新课程 + 新增/更新一条安排）、种子数据、多课表管理。
- 仅 debug 包首次启动写入示例课程（高数、英语、数据结构、体育、操作系统、程序设计实验）；release 只创建空学期与空课表。

### 课表界面

- 真实数据渲染，按当前周过滤：`startWeek..endWeek` + 单双周（奇/偶）。
- 周次切换（上一周 / 下一周 / 回到本周），按开学日期自动定位当前周。
- 重叠课程自动分栏（贪心分道），今天所在列淡色高亮。
- 点击空白格：按该天该节预填添加课程；点击课程：详情（编辑 / 删除，删除有二次确认）。
- 课程编辑：课程名、教师、教室、星期、起始节、连续节数、起止周、单双周、6 种颜色。
- 平板宽屏（≥840dp）：左侧课表 + 右侧「本周课程」列表。
- 手机紧凑模式：时间列 40dp，每天列有最小宽度 64dp，7 天时整表可横向滚动；字体与内边距自适应。

### 学期与多课表

- 学期设置：名称、开学日期（Material 3 DatePicker）、总周数、每天节数、显示周六/周日。
- 多课表：右上角菜单切换 / 新建；设置页单选切换、删除（保留至少一张）。
- 动态取色开关已真正生效（SharedPreferences 持久化），非 Android 12 回退到内置配色。

### 数据导入导出

- 设置 → 数据：
  - **导出当前课表**：系统文件选择器（SAF CreateDocument），生成 FallAsleep JSON 备份，包含学期、课表名、课程与上课安排、节次时间。
  - **导入课表**：SAF OpenDocument，支持 FallAsleep JSON 备份与旧版 WakeUp `.wakeup_schedule`（5 行 JSON）。
- 导入会新建一张课表并自动切换过去；重名自动加「（导入）」；失败弹窗提示原因。
- 已验证：
  - 导出的 JSON 重新导入得到 6 门课，数据完整；
  - 旧版格式导入出「旧版课表」，2 门课，星期/节次/周次/单双周/教室/教师均正确。

### 今日页

- 按「实际周 + 今天星期」显示当天课程，使用节次时间显示起止时间；无课显示空状态。

## UI 调整（2026-10-29）

- 平板导航栏不再依赖 NavigationSuiteScaffold 的内置 Rail：改为自绘 `Surface + NavigationRailItem`，上下用 `weight` 占位实现纵向居中，背景贯穿整屏高度。
- 关闭 `window.isNavigationBarContrastEnforced`，手势提示线后的系统对比底色消失，实现沉浸。
- 移除顶栏「更多」菜单；右下角改为无文字圆形 FAB，点击后在原位向上展开小 FAB：添加课程 / 教务导入 / 切换课表 / 新建课表。展开时**整个界面**（含顶栏、侧栏/底部导航、状态栏区域）覆盖 32% scrim，FAB 组浮在遮罩之上；点遮罩收起，主按钮变成 ×。
- 收起状态下，主 FAB 上方还有一个同尺寸 FAB（MyLocation 准星图标，无文字），点击回到当前周；展开操作时隐藏。
- 手机端改为自绘底部 `NavigationBar`，与平板共用同一套目的地状态，避免双重 inset。

- 宽屏右栏由「本周课程」改为「今日课程」：只列今天星期几的课；按当前时间与节次结束时间比较，已结束的课彩色圆点变灰、课程名加删除线并降低辅助文字亮度，每 30 秒自动刷新。
- 「今日」Tab 的课程卡片套用同一套已结束样式（灰点、删除线、时间与教室/教师文字变淡），同样每 30 秒刷新。

## 已知问题 / 待办

1. **ICS/CSV 未做**：新 JSON 与旧版 `.wakeup_schedule` 已支持；ICS/CSV 留到 P1。
2. 节次时间目前只有默认值，UI 尚不能改每一节的上下课时间。
3. 课表重命名已支持：设置 → 课表，每行重命名按钮（铅笔）在删除按钮左侧。
4. 三门以上课程完全重叠时会分成更多窄栏，手机上文字会很挤。
5. 安装到设备时，`priv` 读不到应用私有目录里的 APK，必须先 `cp` 到 `/sdcard/cccodroid/` 再 `priv cp` 到 `/data/local/tmp/`；否则会静默装回旧包（本次踩过）。
6. 横屏手机（高度 < 480dp）未单独优化，课表以纵向滚动为主。
