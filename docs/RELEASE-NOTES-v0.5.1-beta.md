## 新增

### 课表分享长图

- 设置 → 数据 → **分享课表长图**。
- 可选主题：当前主题 / 浅色 / 深色；可选范围：当前周 / 整学期。
- 可关闭教师、教室；生成 PNG 后通过系统分享面板保存或发送。
- 课程块沿用课表的颜色、圆角与重叠分栏；标题含课表名、学期、周次和日期。
- 单周图 2 倍尺寸，整学期图自动降采样，避免位图过大。

### 课程搜索

- 课表页右上角新增搜索按钮。
- 按课程名、教师、教室搜索当前学期下的所有课表。
- 结果点击后自动切换到对应课表，并跳到当前周或该安排的第一个有效周。
- 支持单双周、起止周与跨课表定位。

### 内部调整

- `visibleSessions()`、`assignLanes()` 移到领域层，课表页、今日页与分享长图共用同一套布局逻辑。
- 新增 FileProvider（仅暴露应用缓存中的分享图片）。
