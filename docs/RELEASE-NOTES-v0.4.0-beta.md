# FallAsleep 课程表 v0.4.0-beta

测试版 · 2026-10-31

- 包名：`io.github.tukinokilyowsoo.fallasleeptimetable`
- 版本：`0.4.0-beta`（versionCode 5）
- APK：`FallAsleepTimetable_arm64_v0.4.0-beta.apk`（arm64-v8a，约 10 MB）
- 系统要求：Android 8.0（API 26）及以上
- 签名：沿用同一 release keystore

## 自 v0.3.0-beta2 以来的变化

### 上课时间
- 改为两步向导：先设上午/下午节数、单节时长、课间、半天起始时间，再逐节微调。
- 自动排课，不再需要“重算”按钮；上午/下午互不影响。
- 时间选择器改为 Material 3 时钟盘，按宽度自适应横/纵布局。

### 系统日历
- 设置 → 数据 → 导入到系统日历：生成「FallAsleep课程表」重复事件，提前 10 分钟提醒。
- 新增“删除当前课表日程”“删除全部已导入日程”。

### 桌面小组件
- 今日课程：2–3 格显示今天，4–5 格显示今天+明天，6 格以上显示三天；上完的课从组件移除，全部结束显示「你已免费，辛苦了喵😋」。
- 周课表：固定显示当前周，跟随学期周六/日设置，重叠分栏、今天列加粗、高度自适应。
- Android 12+ 莫奈取色；设置 → 小组件可切换深色/浅色/跟随系统。
- 小组件使用 M3 圆角与语义色。

### 其他
- 课表页全屏查看。
- 自定义主题色（色板 + 十六进制）。
- 设置课表列表增加重命名按钮。
- 主 FAB 上方增加“回到本周”定位按钮。
- 导入系统日历的事件带课表标记，可按课表删除。

## 安装说明

- 本 APK 仅包含 **arm64-v8a**，适用于近年的 Android 手机/平板。
- 包名与 v0.3.0-beta2 相同，可直接覆盖升级；与更早的 beta1/debug 包是不同应用，可共存。
- 数据不跨包迁移：旧版可先在 设置 → 数据 → 导出当前课表，再在新版导入。

## 已知限制

- 老正方/强智仅通过合成样例验证，欢迎提供真实学校页面 HTML。
- 小组件不能滚动；已结束课程移除依赖刷新（打开 App 立即，最迟 30 分钟）。
- 上课时间目前只有上午/下午两段，晚课归入下午段。
- 尚无 ICS/CSV 导入导出、分享长图、课程搜索（见剩余功能计划）。
- 仓库暂无 LICENSE，当前保留所有权利。
