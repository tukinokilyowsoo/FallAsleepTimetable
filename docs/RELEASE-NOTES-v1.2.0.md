离线、无广告、完全免费的 Material You 课程表。1.2 正式版带来界面重设计、今日时间轴小组件、Material 3 配色与更安心的教务导入。

## 本次更新

### 界面

- 今日页改为时间轴：大日期标题、时间列、线路与节点，正在上的课高亮，已结束的课淡化。
- 平板课表与今日面板可独立滑动淡入淡出；预测式返回会露出下层课表。
- 课表页全屏放大动画；右下角 FAB 展开时加号旋转成叉。
- 新增五页欢迎页，最后一页「开始使用」直接进入教务导入。
- 分享、长图、JSON / CSV 导出与文件导入集中到主页右上角「分享与导出」；设置只保留日历导出与数据管理。

### 配色

- 默认主题与自定义主题色统一按 Material 3 语义角色生成：primary / secondary / tertiary、surfaceContainer 层级、inverse 色与 surfaceTint。
- 自定义主题色新增 12 组 Material 调色板预设，并加入 HSV 色环、明度滑杆与实时课表卡片预览。
- 十六进制输入与色环双向联动；文字色按 WCAG 对比度自动择优。

### 小组件

- 新增「今日时间轴」小组件：按时间顺序显示今天剩余课程，当前课程高亮，高度自适应。
- 原有今日课程、周课表组件继续支持单独选择课表与显示项。

### 教务导入

- 导入页新增电脑版 / 手机版 UA 切换按钮，适配只对电脑浏览器提供完整课表的教务系统；切换后自动重载并记住选择。
- 保留正方（新 / 旧）与强智三套模板识别，以及覆盖当前课表选项。

### 安全与稳定性

- 教务网址只允许 http / https；WebView 关闭文件与内容访问，降低混合内容等级，退出时清除 Cookie，页面大小设上限。
- 导入文件限制 10 MB；导入日志对 password / token / session 等字段脱敏。
- 小组件配置校验 appWidgetId 与 provider，刷新广播增加 action 白名单。
- 修复欢迎页高频重组、联系页头像轻微抖动等问题。

## 升级说明

- 与 v1.1.0、v1.2.0-beta1 使用相同的 release 签名，可直接覆盖安装并保留数据。
- 从 debug 版升级仍需卸载重装（签名不同），建议先导出 JSON。
- 数据库结构与 beta1 一致，无需额外迁移。

## 已知问题

- 教务页面改版可能导致解析失效，可通过「导出日志」反馈页面 HTML 片段。
- 解析模板覆盖正方（新 / 旧）与强智，其他教务系统暂不支持。
- 小组件的下课精准刷新依赖「闹钟和提醒」权限；未授权时最长约 30 分钟刷新一次。
- 预测式返回的完整手势动画需要 Android 13+。
