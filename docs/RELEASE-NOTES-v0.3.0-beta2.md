# FallAsleep 课程表 v0.3.0-beta2

测试版 · 2026-10-30

- **包名变更**：`io.github.tukinokilyowsoo.fallasleeptimetable`（上一版是 `io.github.fallasleeptimetable`）
- 版本：`0.3.0-beta2`（versionCode 4）
- 安装包：`app-release.apk`，约 8.4 MB
- 系统要求：Android 8.0（API 26）及以上
- 签名：与 v0.3.0-beta1 相同的 release keystore

## 关于包名变更

- 新包名在系统里是**另一个应用**，可以和旧版 beta1 / debug 版**同时安装**；
- 两个应用的数据互不相通，旧版课表不会自动迁移到新版；
- 想迁移：在旧版 设置 → 数据 → 导出当前课表，保存 JSON；在新版 设置 → 数据 → 导入课表；
- 不想保留旧版时，安装新版后手动卸载旧版即可。

## 本版包含

- 多课表、周次/单双周、重叠分栏、今日高亮、全屏查看
- 课程增删改、空白格快速添加、颜色
- 学期与上课时间：上午/下午节数、单节时长、课间、逐节起止（Material 3 时间盘）
- 教务导入：新版正方 / 老正方 / 强智 + WebView 登录、预览、重命名、失败日志
- JSON 备份、旧版 `.wakeup_schedule` 导入
- 动态取色与自定义主题色、深浅色、手机/平板自适应
- 今日页已结束课程标记

## 已知限制

- 教务解析：新版正方已在真实学校页面验证；老正方/强智只有合成样例。
- 自定义主题色为 HSV 近似 M3，不是完整 HCT。
- 时间设置只有上午/下午两段，晚课归入下午段。
- 暂无上课提醒、桌面小组件、ICS/CSV（M3 后续）。
