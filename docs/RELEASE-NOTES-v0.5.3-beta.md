## 新增

### Niagara 透明今日课程组件

- 桌面小组件中新增「今日课程（透明）」，适配 Niagara Launcher 等支持自由缩放的启动器。
- 仅显示当天尚未结束的课程，按节次排序。
- 极简待办式单行：课程名大号主文字，第 n 节 / 起止时间 / 教室小号右对齐，仍在一行内横向排列。
- 背景完全透明；文字默认按壁纸亮度自动取黑/白，可在设置中强制黑色或白色。
- 支持任意宽高缩放：
  - 用实际字体测量课程名与说明文字宽度，课程名字号按剩余宽度铺满；
  - 高度按设置行数均分，课程少时下方留空，字号稳定；缩得太矮时临时减少行数；
  - 自动字号上限 72sp，取“宽度铺满”和“行高”的较小值；右侧留 40dp 避开 Niagara 字母索引条。
- 设置 → 小组件 → 「Niagara 小组件」：一个弹窗集中设置显示行数（1–8）、字号（自动/12–40sp）和文字颜色（自动/黑色/白色）。
- 手动字号优先于自动排版：空间不足时减少行数，仍放不下则隐藏右侧说明文字。
- 已接入下课精确刷新、跨天、改时区、开机、壁纸变化与数据变化刷新。

### 刷新逻辑

- 三套小组件的刷新请求合并到单一通道，120ms 内的连续请求只执行一次；
- 刷新与闹钟排程在同一协程串行执行，避免重复更新和重复排程；
- 没有添加任何小组件时取消旧闹钟；只有周课表组件时只在次日零点刷新；
- 精确闹钟权限变更后立即重新排程。
- 当天课程全部结束显示「今天的课已经结束」，无课显示「今天没有课」。

## 已知问题

- 自动模式会在组件较矮时减少显示行数；手动字号过大时会隐藏右侧说明。
- 自动黑白取色基于整张壁纸亮度，壁纸明暗反差很大时可能与组件所在区域不一致，可手动指定颜色。
