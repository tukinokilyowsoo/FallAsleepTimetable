## 已完成：修改上课时间

> 第一版实现已废弃并 revert；当前实现改为两步向导 + 自动排课 + 自适应 M3 时间选择器。

入口：设置 → 学期 → **本学期** → 右侧「设置」菜单 → **修改上课时间**（同一菜单里还有「编辑学期信息」）。

### 第 1 步 · 总体设置

- **上午课程数**（1–12 节）
- **下午课程数**（0–12 节）
- **一节课时长**（20–120 分钟，步进 5）
- **课间休息**（0–30 分钟，步进 5）
- 上午第一节课开始时间
- 下午第一节课开始时间（下午课程数为 0 时隐藏）

按钮：取消 / **下一步**。

点“下一步”时，如果总体参数有改动，会**按当前参数重新生成全部节次时间**：
上午从上午起点排、下午从下午起点排，各自按“时长 + 课间”顺延。
因此下午第一节一定从设定的“下午第一节课开始”时间起算。

### 第 2 步 · 每节课时间

- 顶部显示摘要：上午 X 节 · 下午 Y 节 · 每节 Z 分钟 · 课间 W 分钟
- 逐节列开始/结束时间，按上午/下午分段
- 单独修改某一节：
  - 改**开始** → 结束自动 = 开始 + 课时长；
  - 改**结束** → 开始自动 = 结束 − 课时长（不足一个课时长会提示错误）；
  - 同段后续节次按课间自动顺延。
  - **上午与下午两段完全独立**：改上午最后一节的开始/结束时间，不会带动下午第一节；下午始终从“下午第一节课开始”起算。
- 按钮：**上一步** / 保存；上一步返回总体设置，参数与已调时间都保留。

### 时间选择器

- 使用 Compose **Material 3 TimePicker**（时钟盘，可切换键盘输入）。
- 自适应布局：可用宽度 ≥ 480dp 时用横向（时间输入 + 时钟并排），否则用纵向（时钟在下），避免时钟数字被裁掉。

### 数据

- 保存时事务更新：`term.periodsPerDay = 上午节数 + 下午节数`，并整表重写该学期的 `time_slot`；
- 课表左侧时间列、今日页起止时间自动读取新时间。

### 代码位置

- `ui/screens/ClassTimeSettingsDialog.kt`：两步向导、自动排课、自适应 M3 TimePicker；
- `ui/screens/SettingsScreen.kt`：入口与回调；
- `data/ScheduleRepository.kt`：`replaceTimeSlots()`；
- `ui/ScheduleViewModel.kt`：`updateTimeSlots()`；
- `data/Daos.kt`：`TimeSlotDao.deleteByTerm()`。

### 说明与限制

- 目前只有“上午/下午”两段；晚课会归在下午段里连续排。若学校晚课与下午间隔很大，需要手动微调，后续可加“晚上课程数 / 晚上开始时间”。
- 减少节数只隐藏多出来的行，不删除已有课程安排。
- 结束时间必须晚于开始时间、且不能超过 24:00，否则保存时提示错误。

## 已完成：导入到系统日历

入口：设置 → 数据 → **导入到系统日历**。

- 首次点击会请求 `READ_CALENDAR` / `WRITE_CALENDAR` 权限；
- 在系统日历里创建（或复用）本地日历「FallAsleep课程表」（账户类型 `LOCAL`）；
- 每次导入先**清空该日历里的旧事件**，再按当前课表重建，避免重复；
- 每条上课安排生成一条重复事件：
  - 标题 = 课程名，地点 = 教室，描述含教师、节次、周次；
  - `RRULE` 按周重复，单双周用 `INTERVAL=2`，起止周用 `COUNT` 控制；
  - 时间取该学期的节次时间表；
- 每条事件写入 **提前 10 分钟** 的系统日历提醒；不发送 App 内通知；
- 课表改动后重新导入一次即可同步；删除课程后旧事件会在下次导入时消失。

### 删除已导入日程

设置 → 数据 提供两个删除入口（都会二次确认）：

- **删除当前课表日程**：只删除当前课表写入的事件。
  - 导入时会给事件写 `CUSTOM_APP_URI = fallasleep://timetable/<id>`，按这个标记删除；
  - 旧版本导入、没有标记的事件不会被这个按钮删除，用下面的“全部删除”。
- **删除全部已导入日程**：清空「FallAsleep课程表」日历里的所有事件。

删除前会检查日历权限；没有权限时先申请。删除只影响系统日历事件，不动 App 内的课表数据。

### 说明与限制

- 依赖系统日历 Provider；个别系统/日历应用不支持本地账户时可能创建失败。
- 导入后如果系统日历里看不到，需要在日历应用里勾选显示「FallAsleep课程表」。
- 提前提醒时间目前固定 10 分钟，后续可做成设置项。
- 不生成 ICS 文件；直接写 CalendarContract。

## 已完成：桌面小组件

使用 Jetpack Glance 实现两个小组件，跟随当前选中的课表。

### 1. 今日课程（自适应）

- 最小 2 格宽，纵向不限；**样式只按横向宽度切换**：
  - `< 240dp`（约 2–3 格）：只显示今天；
  - `240–380dp`（约 4–5 格）：今天 + 明天，左右两栏；
  - `≥ 380dp`（约 6 格及以上）：今天 + 明天 + 后天，三栏。
- 每天显示：日期标题、课程时间 + 课程名、教室/教师。
- 今天的已结束课程用灰色块显示。
- 点击打开 App。

### 2. 周课表

- 最小 5 格宽；显示「第 N 周」和左右切周箭头；
- 天数列跟随学期设置：勾了周六/周日就多显示对应列；
- 按节次定位课程块，重叠课程自动分栏；今天所在列加粗；
- 高度自适应：每节格子高度按组件高度计算（12–36dp），宽度足够时文字更完整；
- 切周使用全局偏移（所有周课表实例同步）；到第一周/最后一周时箭头不再变化。

### 小组件样式设置

设置 → 小组件 → **小组件样式**：

- 跟随系统（默认）
- 浅色
- 深色

修改后立即刷新所有小组件。小组件本身使用 Material 3 的圆角、表面色与容器色；不跟随 App 的动态取色/自定义主题色。

### 刷新与限制

- 刷新：系统 30 分钟周期 + 打开 App、修改课程/时间、切换课表、导入后立即刷新。
- 小组件内容不能滚动，课程很多时需要把组件拉高。
- 小组件配色由「小组件样式」控制，不跟随动态取色/自定义主题色。
- 周课表的周偏移是全局的，不是每个实例独立；切周按钮改为 Glance Button，修复此前点击无反应的问题。
- 暂未做小组件配置界面（固定使用当前课表）。
