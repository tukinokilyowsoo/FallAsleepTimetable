## 已完成：修改上课时间

> 第一版实现已废弃并 revert；当前实现改为两步向导 + 自动排课 + 自适应 M3 时间选择器。

入口：设置 → 学期 → **本学期** → 右侧「设置」菜单 → **修改上课时间**（同一菜单里还有「编辑学期信息」）。

### 第 1 步 · 总体设置

- **上午课程数**（1–12 节）
- **下午课程数**（0–12 节）
- **一节课时长**（20–120 分钟，步进 5）
- **课间休息**（0–30 分钟，步进 5）
- 上午第一节课开始时间
- 下午第一节课开始时间（下午课程数为 0 时隐藏）

按钮：取消 / **下一步**。

点“下一步”时，如果总体参数有改动，会**按当前参数重新生成全部节次时间**：
上午从上午起点排、下午从下午起点排，各自按“时长 + 课间”顺延。
因此下午第一节一定从设定的“下午第一节课开始”时间起算。

### 第 2 步 · 每节课时间

- 顶部显示摘要：上午 X 节 · 下午 Y 节 · 每节 Z 分钟 · 课间 W 分钟
- 逐节列开始/结束时间，按上午/下午分段
- 单独修改某一节：
  - 改**开始** → 结束自动 = 开始 + 课时长；
  - 改**结束** → 开始自动 = 结束 − 课时长（不足一个课时长会提示错误）；
  - 同段后续节次按课间自动顺延。
  - **上午与下午两段完全独立**：改上午最后一节的开始/结束时间，不会带动下午第一节；下午始终从“下午第一节课开始”起算。
- 按钮：**上一步** / 保存；上一步返回总体设置，参数与已调时间都保留。

### 时间选择器

- 使用 Compose **Material 3 TimePicker**（时钟盘，可切换键盘输入）。
- 自适应布局：可用宽度 ≥ 480dp 时用横向（时间输入 + 时钟并排），否则用纵向（时钟在下），避免时钟数字被裁掉。

### 数据

- 保存时事务更新：`term.periodsPerDay = 上午节数 + 下午节数`，并整表重写该学期的 `time_slot`；
- 课表左侧时间列、今日页起止时间自动读取新时间。

### 代码位置

- `ui/screens/ClassTimeSettingsDialog.kt`：两步向导、自动排课、自适应 M3 TimePicker；
- `ui/screens/SettingsScreen.kt`：入口与回调；
- `data/ScheduleRepository.kt`：`replaceTimeSlots()`；
- `ui/ScheduleViewModel.kt`：`updateTimeSlots()`；
- `data/Daos.kt`：`TimeSlotDao.deleteByTerm()`。

### 说明与限制

- 目前只有“上午/下午”两段；晚课会归在下午段里连续排。若学校晚课与下午间隔很大，需要手动微调，后续可加“晚上课程数 / 晚上开始时间”。
- 减少节数只隐藏多出来的行，不删除已有课程安排。
- 结束时间必须晚于开始时间、且不能超过 24:00，否则保存时提示错误。

## 已完成：导入到系统日历

入口：设置 → 数据 → **导入到系统日历**。

- 首次点击会请求 `READ_CALENDAR` / `WRITE_CALENDAR` 权限；
- 在系统日历里创建（或复用）本地日历「FallAsleep课程表」（账户类型 `LOCAL`）；
- 每次导入先**清空该日历里的旧事件**，再按当前课表重建，避免重复；
- 每条上课安排生成一条重复事件：
  - 标题 = 课程名，地点 = 教室，描述含教师、节次、周次；
  - `RRULE` 按周重复，单双周用 `INTERVAL=2`，起止周用 `COUNT` 控制；
  - 时间取该学期的节次时间表；
- 每条事件写入 **提前 10 分钟** 的系统日历提醒；不发送 App 内通知；
- 课表改动后重新导入一次即可同步；删除课程后旧事件会在下次导入时消失。

### 删除已导入日程

设置 → 数据 提供两个删除入口（都会二次确认）：

- **删除当前课表日程**：只删除当前课表写入的事件。
  - 导入时会给事件写 `CUSTOM_APP_URI = fallasleep://timetable/<id>`，按这个标记删除；
  - 旧版本导入、没有标记的事件不会被这个按钮删除，用下面的“全部删除”。
- **删除全部已导入日程**：清空「FallAsleep课程表」日历里的所有事件。

删除前会检查日历权限；没有权限时先申请。删除只影响系统日历事件，不动 App 内的课表数据。

### 说明与限制

- 依赖系统日历 Provider；个别系统/日历应用不支持本地账户时可能创建失败。
- 导入后如果系统日历里看不到，需要在日历应用里勾选显示「FallAsleep课程表」。
- 提前提醒时间目前固定 10 分钟，后续可做成设置项。
- 不生成 ICS 文件；直接写 CalendarContract。

## 已完成：ICS / CSV 导入导出

> v0.5.0-beta。纯 Kotlin 实现，不依赖网络；解析器有 JVM 单元测试。

### 入口

设置 → 数据：

- **导出 JSON 备份**：完整备份，可在本应用恢复；
- **导出 ICS 日历**：生成 `.ics`，可导入系统日历、Google 日历等；
- **导出 CSV 表格**：生成 UTF-8 BOM 的 `.csv`，可用 Excel 打开或导入其他课程表工具；
- **导入课表**：自动识别 JSON / 旧版 `.wakeup_schedule` / ICS / CSV，导入为新课表。

### ICS

- 导出：每次上课安排一个 `VEVENT`，`RRULE` 表达连续周与单双周
  （单双周 `INTERVAL=2`，`COUNT` 为实际周数）；
- 时间用浮动时间（设备本地墙钟），换时区上课时间仍按当地时间；
- 文本按 RFC 5545 转义，并按 75 字节折行，中文课程名不会被截断；
- 额外写入 `X-FALLASLEEP-*`（开始/结束周、单双周、开始节次、节数、教师），
  本应用重新导入时精确还原；其他日历会忽略这些属性；
- 导入第三方 ICS：按 `DTSTART` 与学期开学日期推算周次、星期，
  按节次时间表反推节次与节数；支持 `TZID`、UTC（`Z`）与浮动时间；
- 跳过全天事件、学期外事件与 `RECURRENCE-ID` 例外事件；同类课程按「课程名 + 教师」合并。

### CSV

- 列：`课程名称,教师,教室,星期,开始节次,节数,开始周,结束周,单双周`；
- UTF-8 BOM + CRLF，Excel 直接打开不乱码；
- 字段含逗号、引号或换行时按 CSV 规则加引号并转义；
- 导入兼容列名别名（课程/课程名/name、老师/teacher、地点/room、周几/星期/day 等）、
  中文/数字/英文星期、`1-16` 周次范围、`3-4` 节次范围和全周/单周/双周；
- 缺少必填列或整行无效时给出明确提示；无效行跳过，不影响其他课程。

### 代码位置

- `data/importer/IcsTimetable.kt`：ICS 导出/导入；
- `data/importer/CsvTimetable.kt`：CSV 导出/导入；
- `data/importer/TimetableFileImporter.kt`：按内容自动识别格式；
- `data/ScheduleRepository.kt`：导入时读取学期与节次时间；
- `ui/ScheduleViewModel.kt`、`ui/screens/SettingsScreen.kt`：导出入口与导入回调；
- `app/src/test/java/.../IcsTimetableTest.kt`、`CsvTimetableTest.kt`：往返与第三方样例测试。

## 已完成：课表分享长图

> v0.5.1-beta。用 Android Canvas 离屏绘制，不经过 WebView。

入口：设置 → 数据 → **分享课表长图**。

- **主题**：当前主题 / 浅色 / 深色；浅色与深色由当前主色派生，和 App 配色一致；
- **范围**：当前周 / 整学期；
- **显示项**：可关闭教师、教室；
- 生成 PNG 后写入应用缓存，通过系统分享面板保存或发送；
- 单周图 2 倍尺寸；整学期图按 1 倍尺寸，超长学期（30 周 × 16 节）自动降到 0.8 倍，避免位图过大；
- 课程块沿用课表的重叠分栏、圆角、容器色与文字色；标题含课表名、学期、周次与日期范围；
- 空课表不生成图片，提示「当前课表还没有课程」。

### 代码位置

- `data/share/ScheduleImageExporter.kt`：离屏绘制与 PNG 编码；
- `data/share/SharePalette.kt`：从 Compose 配色生成分享用 ARGB 色板；
- `data/share/ShareLauncher.kt`：缓存文件 + FileProvider + 系统分享；
- `ui/screens/ShareImageDialog.kt`：主题/范围/显示项对话框；

## 已完成：课程搜索

入口：课表页右上角**搜索**图标。

- 按**课程名 / 教师 / 教室**模糊搜索，范围是当前学期下的所有课表；
- 结果按课程与上课安排逐条列出：课程名、课表名、星期、节次、周次、教师、教室；
- 点击结果：自动切换到该课程所在课表，并跳到**当前周**（若该周有课）或该安排的**第一个有效周**；
- 单双周、起止周、跨课表都能正确定位；空关键词不查询，无结果给出提示。
