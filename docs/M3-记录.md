## 已完成：修改上课时间

> 第一版实现已废弃并 revert；当前实现改为两步向导 + 自动排课 + 自适应 M3 时间选择器。

入口：设置 → 学期 → **本学期** → 右侧「设置」菜单 → **修改上课时间**（同一菜单里还有「编辑学期信息」）。

### 第 1 步 · 总体设置

- **上午课程数**（1–12 节）
- **下午课程数**（0–12 节）
- **一节课时长**（20–120 分钟，步进 5）
- **课间休息**（0–30 分钟，步进 5）
- 上午第一节课开始时间
- 下午第一节课开始时间（下午课程数为 0 时隐藏）

按钮：取消 / **下一步**。

点“下一步”时，如果总体参数有改动，会**按当前参数重新生成全部节次时间**：
上午从上午起点排、下午从下午起点排，各自按“时长 + 课间”顺延。
因此下午第一节一定从设定的“下午第一节课开始”时间起算。

### 第 2 步 · 每节课时间

- 顶部显示摘要：上午 X 节 · 下午 Y 节 · 每节 Z 分钟 · 课间 W 分钟
- 逐节列开始/结束时间，按上午/下午分段
- 单独修改某一节：
  - 改**开始** → 结束自动 = 开始 + 课时长；
  - 改**结束** → 开始自动 = 结束 − 课时长（不足一个课时长会提示错误）；
  - 同段后续节次按课间自动顺延。
  - **上午与下午两段完全独立**：改上午最后一节的开始/结束时间，不会带动下午第一节；下午始终从“下午第一节课开始”起算。
- 按钮：**上一步** / 保存；上一步返回总体设置，参数与已调时间都保留。

### 时间选择器

- 使用 Compose **Material 3 TimePicker**（时钟盘，可切换键盘输入）。
- 自适应布局：可用宽度 ≥ 480dp 时用横向（时间输入 + 时钟并排），否则用纵向（时钟在下），避免时钟数字被裁掉。

### 数据

- 保存时事务更新：`term.periodsPerDay = 上午节数 + 下午节数`，并整表重写该学期的 `time_slot`；
- 课表左侧时间列、今日页起止时间自动读取新时间。

### 代码位置

- `ui/screens/ClassTimeSettingsDialog.kt`：两步向导、自动排课、自适应 M3 TimePicker；
- `ui/screens/SettingsScreen.kt`：入口与回调；
- `data/ScheduleRepository.kt`：`replaceTimeSlots()`；
- `ui/ScheduleViewModel.kt`：`updateTimeSlots()`；
- `data/Daos.kt`：`TimeSlotDao.deleteByTerm()`。

### 说明与限制

- 目前只有“上午/下午”两段；晚课会归在下午段里连续排。若学校晚课与下午间隔很大，需要手动微调，后续可加“晚上课程数 / 晚上开始时间”。
- 减少节数只隐藏多出来的行，不删除已有课程安排。
- 结束时间必须晚于开始时间、且不能超过 24:00，否则保存时提示错误。

- 全屏时隐藏：系统状态栏与导航栏、顶部标题栏、左侧/底部导航、FAB、右侧“今日课程”；
- 课表铺满，周次切换、抓取全屏按钮仍可用；
- 返回键退出全屏；退出后恢复系统栏与所有导航。

### 自定义主题色

- 设置 → 外观，在「动态取色」下方新增「自定义主题色」；
- 两行的前置图标统一为**调色盘**（`ic_palette` 矢量图标）；
- 点「自定义主题色」弹窗：
  - 12 个预设种子色；
  - 十六进制输入（`#RRGGBB`），实时校验；
  - 颜色预览；
- 应用后自动关闭动态取色，并按种子色生成浅色/深色两套配色；重启保留；
- 再次打开动态取色则由壁纸取色覆盖，关闭后回到自定义色；没有自定义色时使用内置配色。

说明：自定义配色是用 HSV 近似生成的 M3 风格色板（未引入 Material Color Utilities），不是完整的 HCT 色调板。

## 验证清单

1. 设置 → 学期 → 本学期 → 右侧「设置」→ 修改上课时间，出现**第 1 步**界面；菜单里同时有「编辑学期信息」。
2. 修改上午/下午节数、时长、课间、上午/下午起始时间，点“下一步”。
3. 第 2 步中，下午第一节应**正好**从设定的“下午第一节课开始”时间起算，后续按课间和时长排列。
4. 点“上一步”回到第 1 步，参数保留；不改参数直接“下一步”，第 2 步已手动调整的时间应保留。
5. 在第 2 步改某节开始时间 → 结束自动加一个课时长；改结束时间 → 开始自动减一个课时长。
6. 点任意时间 → Material 3 时钟盘；宽屏横向、窄屏纵向，数字不被裁切。
7. 保存后：设置摘要“每天 N 节”更新；课表左侧时间列、今日页时间同步。
8. 结束早于开始或超过 24:00，保存应报错。
9. 取消不写入。
10. 回归：学期设置、教务导入、JSON/旧版导入、FAB、今日页样式正常。
11. 上午/下午独立：在第 2 步修改上午最后一节的结束时间，下午第一节的开始时间应保持不变（仍为第 1 步设定的下午起始时间）。
12. 课表页：标题与课表整体上移，标题栏下方只有合适间距，不再有大片留白。
13. 设置 → 外观：「动态取色」「自定义主题色」前面都是调色盘图标。
14. 自定义主题色：选预设或输入 #RRGGBB → 应用后界面立即换色，动态取色开关自动关闭；杀进程重启后仍是该主题色。
15. 主题色弹窗：非法十六进制显示错误且“应用”不可用；取消不改变当前主题。
16. 全屏：点周次行的全屏按钮 → 系统栏、标题、导航、FAB、右侧今日课程都隐藏，课表铺满；按钮变为退出图标；再点或按返回键恢复。
