## 4. 技术要点

- **ICS**：VEVENT + RRULE（`FREQ=WEEKLY;INTERVAL=2;COUNT=n`），时区取系统；导入需解析多事件并按课程名聚合。
- **CSV**：定义固定列名并兼容常见第三方格式；导出采用 UTF-8 BOM 便于 Excel。
- **分享图**：Compose 绘制离屏 Bitmap（或 Canvas 自绘），按当前主题取色，避免 WebView。
- **小组件精准刷新**：按当天课程结束时间注册 `AlarmManager` 一次性闹钟（或 WorkManager 精确任务），触发 `WidgetUpdater`；跨天用 `DATE_CHANGED` 接收器。
- **多学期**：Term 增加归档标记；所有查询按当前 Term 过滤；切换走统一状态。
- **测试**：解析器 fixtures 放 `app/src/test/resources`，禁止提交含个人信息的真实 HTML。
