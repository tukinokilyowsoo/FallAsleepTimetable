# FallAsleep 课程表 v1.1.0-beta1

离线、无广告、完全免费的 Material You 课程表。第一个 1.1 测试版，重点是把上课时间交给每张课表自己管理，并补齐导入与更新提醒体验。

- 版本：`1.1.0-beta1`（versionCode 20）
- 包名：`io.github.tukinokilyowsoo.fallasleeptimetable`
- APK：`FallAsleepTimetable_arm64_v1.1.0-beta1.apk`（arm64-v8a，10,801,971 字节）
- SHA-256：`6c59d914304b7f7714ec9e6ab442cb24d7f511037484d3e6862a2a3d0ec5e417`
- 最低系统：Android 8.0（API 26）
- 语言：简体中文

## 本次更新

### 上课时间按课表独立

- 每张课表拥有自己的每天节数与每节课起止时间，不再共用一个学期时间表。
- 新建课表默认复制当前课表的配置。
- 设置 → 学期 →「修改上课时间」会先选择目标课表；时间设置弹窗内可打开「将当前时间作用全局」，一次同步到所有课表。
- 学期设置中不再重复提供「每天节数」，避免两处配置冲突。
- 首次启动新版会自动迁移旧数据：原有学期时间会复制给每一张已有课表，课表与课程不受影响。

### 导入

- 教务导入预览页新增「覆盖当前课表」：清空目标课表的课程后写入新课程，保留课表名称与上课时间设置，不再弹出重命名。
- 关闭该选项时仍新建课表，并默认沿用当前课表的上班时间。
- JSON 备份选择「一并恢复」时，开学日期与周数写入学期，节次时间写入新导入的课表，不再影响其他课表。

### 图标与欢迎页

- 应用图标改为 Material 3 自适应图标：规范安全区、圆形/方圆遮罩适配，并提供 Android 13+ 单色主题图标。
- 欢迎页删除全局「下一步」，第 5 页以胶囊按钮「开始使用」直接进入教务导入；文案同步调整。

### 检查更新

- 「检查更新」移入版本行右侧，左侧保留「拒收更新提醒 / 接收更新提醒」。
- 启动时检查更新，发现新版本后主页底部弹出 Snackbar，右侧提供「更新」入口；可随时拒收提醒。
- 教务系统网址会记住上次输入，并可在设置 →「教务导入」中修改或清空。

## 升级说明

- 与 v1.0.0 使用相同的 release 签名，可直接覆盖安装并保留数据。
- 从 debug 版升级仍需卸载重装（签名不同），建议先导出 JSON。
- 本次包含数据库升级，首次启动会自动迁移；降级到旧版本不受支持。

## 已知问题

- 测试版功能与交互仍可能调整，欢迎反馈。
- 「覆盖当前课表」目前用于教务导入；文件导入仍默认新建课表。
- 教务页面改版可能导致解析失效，可通过「导出日志」反馈页面 HTML 片段。
- 解析模板覆盖正方（新 / 旧）与强智，其他教务系统暂不支持。
- 小组件的下课精准刷新依赖「闹钟和提醒」权限；未授权时最长约 30 分钟刷新一次。
