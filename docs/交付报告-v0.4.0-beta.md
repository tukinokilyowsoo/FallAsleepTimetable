## 1. 项目概况

一个 Material You（Material 3）风格的 Android 课程表应用：离线、无账号、无自建后端，支持手机/平板自适应、教务系统导入、系统日历同步和桌面小组件。

- 技术栈：Kotlin 2.3、Jetpack Compose、Material 3、Room、Glance、jsoup
- 最低系统：Android 8.0（API 26），targetSdk 36
- 仓库：https://github.com/tukinokilyowsoo/FallAsleepTimetable（公开）
- 代码规模：31 个 Kotlin 文件，约 7,500 行；干净提交历史
- 签名：独立 release keystore（备份见 `docs/RELEASE-流程.md`）

## 3. 已交付功能

### 3.1 数据与课表

- Room 五表模型：学期、课表、课程、上课安排、节次时间；外键级联。
- 多课表：新建、切换、重命名、删除（至少保留一张）。
- 学期设置：开学日期、总周数、每天节数、周六/周日显示。
- 上课时间两步向导：上午/下午节数、单节时长、课间、每节起止；M3 时间盘；上午/下午独立计算。
- 课表网格：周次切换、当前周定位、单双周、起止周、重叠课程分栏、今日列高亮、非本周淡化。
- 课程：增删改、颜色、教师/教室/备注、空白格快速添加、详情弹窗。
- 全屏查看：隐藏系统栏、标题栏、导航与 FAB，课表铺满。
- 今日页：当天课程、已结束课程灰点 + 删除线。
- 宽屏：平板双栏（课表 + 今日课程列表）。

### 3.2 导入导出

- 教务导入：内置 WebView 手动登录 → 抓取当前课表页 → 本地解析 → 预览 → 导入 → 重命名。
  - 支持新版正方 jwglxt、老正方、强智三套模板；自动识别；支持 iframe 页面。
  - 失败可导出日志（含页面 HTML）用于排查。
- 文件：FallAsleep JSON 备份导入/导出；旧版 WakeUp `.wakeup_schedule` 导入。

### 3.3 系统集成

- 导入到系统日历：创建本地日历「FallAsleep课程表」，按周次/单双周生成重复事件，提前 10 分钟提醒。
- 删除当前课表日程 / 删除全部已导入日程（二次确认 + 权限检查）。

### 3.4 桌面小组件（Glance）

- 今日课程：最小 2 格宽，按宽度显示今天 / 今天+明天 / 今天+明天+后天；上完的课移除，全部结束显示「你已免费，辛苦了喵😋」。
- 周课表：最小 5 格宽，固定当前周；跟随学期周六/日设置、重叠分栏、今天列加粗、高度自适应。
- 外观：M3 圆角与语义色；Android 12+ 莫奈取色；设置中可选深色/浅色/跟随系统（与“本学期”同款「设置」按钮 + 下拉菜单）。
- 刷新：打开 App、修改数据、切换课表、导入后立即刷新；系统周期 30 分钟。

### 3.5 外观与体验

- Material 3 + 动态取色 + 自定义主题色（色板/十六进制）。
- 手机底部导航、平板侧栏（纵向居中）、手势条沉浸。
- 课表 FAB：添加课程 / 教务导入 / 切换课表 / 新建课表，全屏遮罩；上方回本周定位按钮。
- 设置：数据管理、日志导出、小组件样式、关于。

### 3.6 发布工程

- 正式签名配置（密钥在应用私有目录，未入库）。
- GitHub 公开仓库、pre-release 流程；APK 命名规范 `FallAsleepTimetable_arm64_vX.Y.Z-beta.apk`。
- arm64-v8a 单 ABI 构建，压缩包体积约 10 MB。

## 5. 已知问题与限制

1. 教务解析只覆盖三套模板；页面改版会失效，需要日志/HTML 样本维护。
2. 小组件内容不可滚动，课程多时需要拉高；刷新最迟 30 分钟（打开 App 会立即刷新）。
3. 已结束课程从小组件移除依赖刷新，做不到“下课当分钟消失”。
4. 小组件不跟随 App 内自定义主题色；Android 11 及以下用固定配色。
5. 上课时间目前只有上午/下午两段，晚课归入下午段。
6. 自定义主题色为 HSV 近似 M3，不是完整 HCT 色调板。
7. 仓库暂无 LICENSE（保留所有权利）；上架商店前需补许可证与隐私政策。
8. 源码 namespace 仍为 `io.github.fallasleeptimetable`，安装包名已改为 `io.github.tukinokilyowsoo.fallasleeptimetable`。
