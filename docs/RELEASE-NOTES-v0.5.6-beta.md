## 本版新增

### Niagara 组件改名

- 桌面小组件名称改为 **「今日课程*针对Niagara优化」**。
- 设置页仍为「设置 → 小组件 → Niagara 小组件」。

### 显示课程数与空行占位

- 新增 **显示课程数** 设置（1–12 节，默认 4），位于 Niagara 设置弹窗内。
- 组件固定显示该数量的行：
  - 剩余课程不足时，用**空行占位**，不再减少行数；
  - 剩余课程多于显示数量时，只显示前 N 门。
- 字号改为按**当天全部课程**测量，而不是仅剩余课程：
  - 随着课程一节节结束，字号不会忽大忽小；
  - 行高按显示课程数均分，空行保持同样高度。
- 旧的「最大行数」设置不再读取，改用新的 `niagara_display_count`。

### 同时包含

- 0.5.5 的 JSON 备份恢复学期设置/节次时间（导入前确认）。
- 0.5.4 的 Niagara 方案 A：仅显示开始时间/课程名/教室、30sp 上限、0.82 安全系数、56dp 右侧安全区。

## 已知限制

- 空行占位不会改变组件外层高度；高度仍由 Niagara 的“移动并调整大小”决定。
- 当天课程全部结束后仍显示「今天的课已经结束」，不再保留空行。
- 「一并恢复」JSON 学期设置会影响当前学期下所有课表，导入前有确认弹窗。
