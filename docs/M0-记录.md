## 构建 / 安装 / 启动

```sh
cd /data/user/0/cc.codroid/files/home/workspace/FallAsleepTimetable
$HOME/gradle-8.14.3/bin/gradle assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

安装（`pm install` 读不了 FUSE 的 `/sdcard` 路径，必须先中转）：

```sh
cp app/build/outputs/apk/debug/app-debug.apk /sdcard/cccodroid/FallAsleep-debug.apk
priv 'cp /sdcard/cccodroid/FallAsleep-debug.apk /data/local/tmp/fa.apk && pm install -r /data/local/tmp/fa.apk'
priv 'am start -n io.github.fallasleeptimetable/.MainActivity'
```

## 已知问题 / M1 待办

1. **导航形态**：1204dp 宽时 `NavigationSuiteScaffold` 仍选了 Rail（M3 期望 expanded 用 Drawer）。
   M1 显式传 `layoutType`（≥840dp 用 Drawer）或升级 adaptive 库时一起处理。
2. 图标用了已废弃的 `Icons.Filled.KeyboardArrowLeft/Right`，应换 `Icons.AutoMirrored.Filled.*`。
3. `@StringRes` 在构造参数上有一条 Kotlin 2.3 的默认目标警告，可加 `@param:StringRes` 消除。
4. 当前全部是 mock 数据，尚无 Room / 仓库层 / 导入模块（M1、M2 内容）。
5. debug 包用 Android Debug 证书签名，安装包约 12MB。
6. 课表格宽在 411dp 手机下偏窄，课程地点会截断；M1 做真实网格时按可用宽度调整字号与内边距。
